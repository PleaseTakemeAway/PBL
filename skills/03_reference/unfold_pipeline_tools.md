# 설계도면 → 전개도 추출 파이프라인

KDM TECH / HCE 도면 데이터를 다루는 도구 모음.
핵심 목표는 **설계도면에서 부품 전개도(flat pattern)를 뽑아내는 것**이다.

---

## 1. 전체 플로우

```
                    ┌──────────────────────────────────────────┐
   설계도면          │  입력이 무엇이냐에 따라 경로가 갈린다      │
   (설계도/POR)      └──────────────────────────────────────────┘
        │
        ├─ [A] DWG 파일           → dwg2png.py      → DXF (벡터 그대로)
        ├─ [B] 스캔 PDF (래스터)   → pdf2dxf.py      → DXF (벡터화)
        └─ [C] 도면 이미지         → vlm2flat.py     → 부품 모델(파라미터)
                                          │
                                          ▼
                               ┌──────────────────────┐
                               │  형상 분류            │
                               │  cylinder / cone /    │
                               │  bent_sheet / flat    │
                               └──────────┬───────────┘
                                          ▼
                               ┌──────────────────────┐
                               │  unfold.py           │
                               │  공학식으로 펴기       │
                               └──────────┬───────────┘
                                          ▼
                                   전개도 DXF
                                          │
                                          ├─ add_dims.py  → 치수 삽입
                                          └─ 네스팅 투입
```

**중요**: [A]/[B]는 *도면을 옮기는* 경로고, [C]만 *전개를 계산하는* 경로다.
전개 블랭크 치수는 도면에 적혀 있지 않다 — 계산해야 나온다.

---

## 2. 형상별 전개 판정

전체 부품의 **약 71%는 전개가 필요 없다** (이미 평판).
KD 도면 67개에서 라벨 779건을 분류한 결과:

| 부품 계열 | 전개 | 전개 형상 | 비중 |
|---|---|---|---|
| SHELL / CHANNEL | ✅ 필요 | 원통 → 직사각형 | 50 |
| CONE | ✅ 필요 | 원뿔 → 부채꼴 | 26 |
| NOZZLE NECK | ✅ 필요 | 원통 + 상관선 | 18 |
| REINF. PAD | △ 조건부 | 쉘 곡률로 성형 | 115 |
| HEAD | △ 조건부 | 블랭크 지름 계산 | 14 |
| BAFFLE / RIB / LUG / PLATE류 | ❌ 불필요 | 평판 | 556 |

**성형품(press-formed)은 전개 계산 대상이 아니다.**
도면 NOTE에 "금형 제작 전 성형해석 DATA 제출" 이 있으면 굽힘이 아니라 드로잉이다.
재료가 2축으로 늘어나 두께가 변하므로 굽힘여유 공식이 성립하지 않는다 (FEA 필요).

## 3. 전개 공식

### 3.1 원통 (cylinder) — SHELL / CHANNEL

```
L = π × (ID + t)          중립축 = 평균지름, K-factor = 0.5
블랭크 = L × 원통길이
```

**이 공식은 추측이 아니라 KDM 도면 태그 44건에서 역산해 검증한 것이다.**

| 가설 | 5mm격자 잔차 중앙값 | ≤2mm | ≤0.5mm |
|---|---|---|---|
| **평균지름 (ID+t)** | **0.02mm** | **43/44** | **33/44** |
| 안지름 (ID) | 1.01mm | 34/44 | 11/44 |
| 바깥지름 (ID+2t) | 1.01mm | 37/44 | 11/44 |

검증 재실행: `py vlm/unfold.py --validate`

### 3.2 원뿔대 (cone_frustum) — CONE

중립면 기준. `D1m = ID_large + t`, `D2m = ID_small + t`

```
s     = √(h² + ((D1m − D2m)/2)²)        모선 길이
R1    = s × D1m / (D1m − D2m)           큰쪽 전개 반지름
R2    = R1 − s                          작은쪽 전개 반지름
θ     = π × D1m / R1                    부채꼴 중심각 (rad)
```

θ > 360° 이면 분할 전개가 필요하다.

### 3.3 절곡 판금 (bent_sheet)

```
BA        = θ × (R + K·t)                  굽힘여유 (중립축 호 길이)
setback   = (R + t) × tan(θ/2)             굽힘에 물리는 길이
전개길이   = Σ(외측구간 − setback) + Σ(BA)
```

K-factor는 R/t 비로 결정:

| R/t | K |
|---|---|
| < 1 | 0.33 |
| 1 ~ 3 | 0.40 |
| ≥ 3 | 0.50 |

롤링(원통·원뿔)은 R/t가 커서 0.5로 수렴 — 3.1의 KDM 관행과 자동으로 일치한다.

### 3.4 평판 (flat)

전개 불필요. 윤곽 그대로 통과.

## 4. 도구

### 본 도구

| 파일 | 용도 | 실행 |
|---|---|---|
| `dwg2png.py` | DWG → DXF → PNG 일괄 변환 | `py dwg2png.py <DWG폴더> <출력폴더>` |
| `pdf2dxf.py` | 스캔 PDF → 벡터화 DXF | `py pdf2dxf.py <pdf> <출력폴더> --sheet A3` |
| `cp_extract.py` | CP 도면 → 네스팅 데이터셋 | `py cp_extract.py "<DXF폴더>[;폴더2]" <출력폴더>` |
| `qc_render.py` | 검출 결과 겹쳐 그리기 | `py qc_render.py <dxf> <png> [sheet_id]` |
| `validate.py` | 데이터셋 필드 검증 | `py validate.py` |
| `scorecard.py` | 도면별 추출 성적표 | `py scorecard.py` |
| `taf_extract.py` | TAF/BOM → 데이터셋 | `py taf_extract.py` |
| `make_flats.py` | 페이지별 전개도 정규화 | `py make_flats.py` |
| `add_dims.py` | 전개도에 치수 삽입 | `py add_dims.py` |
| `render_dxf.py` | DXF → PNG 확인용 | `py render_dxf.py <dxf> <png>` |

### VLM (`vlm/`)

| 파일 | 용도 |
|---|---|
| `unfold.py` | **전개 계산 엔진** (API 불필요, 단독 실행 가능) |
| `vlm2flat.py` | 도면 이미지 → VLM → 전개도 DXF |
| `vlm2dxf.py` | 도면 이미지 → VLM → 형상 DXF (전개 아님) |
| `prompts/unfold_extract.md` | 전개 파라미터 추출 프롬프트 |
| `prompts/dxf_extract.md` | 형상 추출 프롬프트 |

```bash
py vlm/unfold.py --validate                    # 전개식 검증 (API 불필요)
py vlm/vlm2flat.py --selftest out_flat         # 엔진 시험 (API 불필요)
py vlm/vlm2flat.py <pdf> <출력폴더> --page 4   # 실제 실행 (API 키 필요)
```

`_scratch/` 는 원인 분석용 일회성 스크립트 모음. 본 도구 동작과 무관하다.

## 5. 실무에서 걸린 것들

파이프라인을 만들며 실제로 부딪힌 함정. 다시 만들 때 참고.

| 단계 | 함정 | 대응 |
|---|---|---|
| DWG→DXF | 한글이 □로 깨짐 (`whtgtxt.shx` 없음) | 한글 포함 텍스트만 맑은고딕으로 재매핑 |
| 판재 인식 | 테두리가 LWPOLYLINE 아닌 LINE 4개 | 전체 클러스터링 후 치수 매칭 |
| 판재 인식 | 테두리 안쪽에 절단여유선이 한 겹 더 | 단순 축정렬 사각형만 경계선으로 판정 |
| 판재 인식 | 클래드강 표기 `t16(13+3)` | 정규식에 괄호 허용 |
| 판재 인식 | 길이 접미사 `1350L` | 정규식에 `L?` 추가 |
| 부품 분리 | 부품이 접해 있어 한 덩어리 | `quality=chain_path` 로 표시 (미해결) |
| 부품 라벨 | 치수선 숫자를 부품명으로 오인 | 미해결 — 숫자 필터 필요 |
| 태그 파싱 | 이름이 문단(`\P`)으로 쪼개짐 | 문단 단위 순차 파싱 |
| 벡터화 | 임계값을 낮추면 글자 획이 끊김 | Otsu 그대로 사용 (`--cut 1.0`) |
| DXF 생성 | 단위 미지정 시 **미터**로 해석 | `doc.units = units.MM` 필수 |
| DXF 생성 | 이미지 Y축과 DXF Y축이 반대 | `y' = img_h - y` |
| 치수 삽입 | ezdxf 기본 스타일이 cm용 (`dimlfac=100`) | 전용 스타일에 `dimlfac=1` |
| 치수 삽입 | 반지름 치수에 `R` 중복 (`RR5`) | 라벨에서 R 제거 (렌더러가 붙임) |
| VLM 입력 | 2576px 초과분은 서버가 축소 | 페이지 크기에서 dpi 역산 |

## 6. 현재 상태

- **완료**: DWG 67개 변환, 네스팅 데이터셋(판재 936 / 부품 13,388), 스캔 10페이지 벡터화,
  전개도 6개 + 치수, 전개 엔진 4형상 검증
- **미검증**: VLM 호출부 (`ANTHROPIC_API_KEY` 없음)
- **미해결**: `chain_path` 81장 부품 분리, `part_label` 숫자 오염, 중복 행 9%
