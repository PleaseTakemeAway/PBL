# 조각 분할(split line)과 커팅 여유 — KDM 발표자료 RQ1 의 대상

## 왜 나누는가
판재는 두께·폭·길이로 **주문제작** 한다. 전개 형상이 판 한 장(운반 상한 12000 × 3050) 에 안 들어가거나,
용접선 배치(WELDING SEAM PLAN)가 이미 정해져 있으면 그 선을 따라 조각을 나눈다.
KD25038 (VP2V901C, 쉘 ID 2600, t10) 사례: 쉘 → SA-01 (8168×1700), SA-02 (8168×2400) 2코스;
TOP HEAD Ø3240 → 폭 2000 판에 맞춰 두 조각(1970×3238 + 1270×3163, 오프셋 350);
BTM CONE → 부채꼴을 둘로 나눠 2604×2604 ×2 (SB-04a/b), 1219×1219 ×2 (SB-05a/b).

## 규칙
1. **쉘**: 코스 길이(H) ≤ 판 폭, 원주 전개(L) ≤ 판 길이. 넘으면 롱심을 추가해 L 을 n 등분, 원주심을 추가해 H 를 나눈다. 도면 용접선이 있으면 그 수를 따른다.
2. **헤드 블랭크**: 지름 D ≤ 판 폭이면 1장. 넘으면 현(弦) 으로 2분할: 큰 조각 높이 = 판 폭 − 여유(15~30), 작은 조각 = D − 큰 조각. 분할선은 중심에서 오프셋(KD25038: 350).
3. **콘 부채꼴**: 부채꼴을 중심각 기준 n 등분해 각 조각의 bbox 가 판 폭 안에 들어오게 한다 (n = 2, 3, 4 …).
4. **패드·러그·소형 평판**: 분할 없음. 자투리에 배치.
5. 분할 조각 이름은 용접선 이름 + a/b (SB-04a, SB-04b).

## 커팅 여유 (조각 간 간격)
- 가스절단 20 mm (KDM 배치툴 기본), 플라즈마 10, 레이저 5. 여유보다 가까우면 충돌.
- 판 가장자리 여유 10 mm.
- 데빗 파이프 등 굽힘 부재는 직선 길이에 절단 마진을 더한다.
- 쉘 전개 길이에는 용접 개선(groove) 여유를 더하지 않는다 (중립축 평균지름 공식이 이미 실측과 일치).

## 판재 선택
- 표준폭 1219 / 1524 / 1829 / 2000 / 2134 / 2438 / 2500 / 2670 / 3048, 길이는 운반 상한 12000 이내 100 단위 맞춤.
- 같은 재질·두께만 같은 판에. 다른 두께는 절대 섞지 않는다.
- 목표: 로스 40% → 22% (활용률 58% → 77%). 멀티규격(판마다 다른 크기) 허용.
- 중량 = t × W × L × 7.85e-6 (kg). POR 은 이 **gross 중량** 으로 적는다.
