# 쉘·콘·헤드 전개와 철판 크기 계산 기준

회사 담당자에게 받은 압력용기 쉘·콘·헤드의 전개 계산 기준이다. 원문은 담당자와 나눈 질의응답 녹음을 AI 가 대화 순서대로 정리한 문서다. 2026-10-23 에 내용을 빼지 않고 부품별 기준 문서로 다시 썼다. 원문은 git 커밋 b399b4d 의 같은 경로에 있다 (sha256 `c9f5b108…`).

이 계산식들은 실무에서 통용되는 방법이다. 최종 치수는 회사·제작사 표준(트림 여유, 롤링 여유 등)과 CAD 전개 결과로 확인하는 것을 권장한다.

7절은 원문에 없는 내용이다. 받은 커팅플랜과 이 기준을 대조한 결과와, 원문 식에서 확인이 필요한 곳을 적었다.

## 1. 공통

### 1.1 평균지름 원칙

모든 전개 계산은 평균지름(Dm, 두께 중앙) 기준이 원칙이다.

- 내경 기준 도면: Dm = ID + t
- 외경 기준 도면: Dm = OD − t

### 1.2 기호

| 기호 | 뜻 |
|---|---|
| ID, OD | 내경, 외경 |
| t | 두께 |
| Dm | 평균지름 |
| D | 원문이 평균지름과 구분하지 않고 쓴 지름 (4.2 의 비고와 평판형 플랜지, 4.3) |
| H | 쉘 길이(축 방향) 또는 콘 높이 |
| D₁, D₂ | 콘의 대경, 소경. 둘 다 평균지름 |
| α | 콘 반정각 |
| S | 콘 경사 길이 |
| R₁, R₂ | 콘의 외측, 내측 전개 반경 |
| θ | 콘 전개 각도 |
| e | 편심 콘의 두 원 중심 간 편심량 |
| Db | 헤드 원판(Blank) 지름 |
| SF | 스트레이트 플랜지 길이 |
| IKR | 내측 너클 반경 (Inside Knuckle Radius) |
| KR | 너클 반경 |
| CR | 크라운 반경 |

### 1.3 공통으로 필요한 수치

| 필요 수치 | 용도 |
|---|---|
| 두께(t) 및 치수 기준(ID 또는 OD) | 평균지름(Dm) 계산 |
| 재질 | 중량 계산, 성형 특성 |
| 트림·가공 여유 | 개선 가공, 절단 여유 |
| 사용 가능한 철판 규격 (예: 2,438 × 6,096 mm) | 분할 여부 결정 |

부품별로 더 필요한 수치는 2.3, 3.1.4, 3.2.6, 4.5 에 있다.

### 1.4 작업 순서

1. 형상 치수(지름, 높이, 반경, 편심량)로 전개 형상을 계산한다.
2. 두께로 평균지름을 보정한다.
3. 이음 위치·여유·철판 규격으로 실제 절단 치수와 분할을 정한다.

## 2. 원통 쉘 (Cylindrical Shell)

### 2.1 계산식

- 전개 길이(원주 방향): L = π × Dm
- 전개 폭(축 방향): W = 쉘 길이(H)
- 철판 크기: (π × Dm) × H

### 2.2 분할과 여유

- 한 장으로 나오지 않으면 여러 코스(Course)로 나눈다. 길이 방향 이음(Long seam)은 코스끼리 엇갈리게 배치한다.
- 롤링 전 양 끝단의 프리벤딩(Pre-bending) 여유나 트림 여유를 제작사 기준에 따라 추가한다.

### 2.3 필요 수치

| 필요 수치 | 용도 |
|---|---|
| 지름 (ID 또는 OD) | 평균지름 → 원주 길이 π·Dm |
| 쉘 길이 (H) | 전개 폭 |
| 두께 (t) | 평균지름 계산 |
| 코스 분할 위치 | 원주 이음(Circ. seam) 위치 결정 |
| 길이 이음 위치/방향 | 코스끼리 엇갈림 배치 |
| 노즐·맨홀 위치와 크기 | 개구부가 용접선을 피하도록 배치 |
| 롤링·프리벤딩 여유 | 실제 절단 치수 |

### 2.4 예제

ID 1,500 mm, t = 12 mm, 길이 3,000 mm

- Dm = 1,512 mm
- L = π × 1,512 ≈ 4,750 mm
- 철판 크기: 4,750 × 3,000 mm

## 3. 콘 (Cone)

### 3.1 동심 콘 (Concentric Cone)

기호: D₁ = 대경, D₂ = 소경 (둘 다 평균지름), H = 콘 높이

#### 3.1.1 계산식

| 항목 | 계산식 |
|---|---|
| ① 반정각 | tan α = (D₁ − D₂) / (2H) |
| ② 경사 길이 | S = √[ H² + ((D₁ − D₂)/2)² ] |
| ③ 외측 전개 반경 | R₁ = D₁ / (2 sin α) |
| ③ 내측 전개 반경 | R₂ = D₂ / (2 sin α) |
| 검산 | R₁ − R₂ = S |
| ④ 전개 각도 | θ = 360° × sin α |

도면에 반정각만 있으면 H = (D₁ − D₂) / (2·tan α) 로 높이를 구한다.

#### 3.1.2 필요 철판 크기 (⑤, 부채꼴 1장 기준)

| 조건 | 철판 폭 | 철판 높이 |
|---|---|---|
| θ ≤ 180° | 2R₁ · sin(θ/2) | R₁ − R₂ · cos(θ/2) |
| θ > 180° | 2R₁ | R₁ · (1 − cos(θ/2)) |

θ 가 크면 2~4분할로 나눈다. n분할하면 각 조각의 각도 θ/n 을 위 표에 대입한다.

#### 3.1.3 예제

D₁ = 2,000 mm, D₂ = 1,000 mm, H = 800 mm

1. tan α = 500 / 800 = 0.625 → α ≈ 32.0°, sin α ≈ 0.530
2. R₁ = 2,000 / (2 × 0.530) ≈ 1,887 mm
3. R₂ ≈ 943 mm
4. θ = 360 × 0.530 ≈ 190.8° (180° 초과)
5. 1장: 약 3,774 × 2,065 mm. 너무 크다.
6. 2분할: 각 조각 95.4° → 조각당 약 2,791 × 1,252 mm, 2장

#### 3.1.4 필요 수치

| 필요 수치 | 용도 |
|---|---|
| 대경 (D₁) | 외측 전개 반경 R₁ |
| 소경 (D₂) | 내측 전개 반경 R₂ |
| 콘 높이 (H) 또는 반정각 (α) | 둘 중 하나만 있으면 나머지 계산 가능 |
| 두께 (t) | 평균지름 계산 |
| 너클·토로이달 유무와 반경 | 있으면 별도 부품으로 전개 |
| 분할 수 | 전개 각도가 크면 2~4분할 |

### 3.2 편심 콘 (Eccentric Cone)

편심 콘을 연장하면 꼭짓점이 한쪽으로 기울어진 사원추(Oblique cone)가 된다. 모선 길이가 위치마다 달라 부채꼴이 되지 않는다. 그래서 둘레를 n등분해 각 점을 계산하는 방사선법/삼각분할법으로 전개한다.

기호: D₁, D₂, H 에 더해 e (두 원 중심 간 편심량). 한쪽 면이 수직인 일반 편심 콘은 e = (D₁ − D₂)/2 다.

#### 3.2.1 가상 꼭짓점 위치 (①)

- 꼭짓점 높이 (대경 기준): Ha = H × D₁ / (D₁ − D₂)
- 꼭짓점 수평 위치 (대경 중심에서): Xa = e × D₁ / (D₁ − D₂)

#### 3.2.2 각 점의 모선 길이 (②)

대경 원주를 n등분한다. φ = 360° × i / n 이고 φ = 0° 는 편심 방향이다. r₁ = D₁/2.

L₁(φ) = √[ (r₁·cos φ − Xa)² + (r₁·sin φ)² + Ha² ]

수직면 편심 콘(Xa = r₁)이면 다음과 같다.

L₁(φ) = √[ 4r₁²·sin²(φ/2) + Ha² ]

- 소경 쪽 모선 길이: L₂(φ) = L₁(φ) × D₂ / D₁
- 실제 콘 경사 길이: S(φ) = L₁(φ) − L₂(φ)

#### 3.2.3 전개 각도 (③, 삼각형 이어붙이기)

- 대경 원주 분할 현 길이: c = D₁ · sin(180°/n)
- 이웃 모선 사이 전개 각: δᵢ = arccos[ (Lᵢ² + Lᵢ₊₁² − c²) / (2·Lᵢ·Lᵢ₊₁) ]
- 누적 각도: ψᵢ = δ₁ + δ₂ + … + δᵢ

#### 3.2.4 전개도 좌표 (④, 꼭짓점 = 원점)

- 대경 쪽 점: (L₁·cos ψ, L₁·sin ψ)
- 소경 쪽 점: (L₂·cos ψ, L₂·sin ψ)

점들을 매끄럽게 이으면 전개도가 된다. 좌표의 최대·최소값으로 철판 크기(외접 사각형)를 구한다.

#### 3.2.5 예제

D₁ = 2,000 mm, D₂ = 1,000 mm, H = 800 mm, 수직면 편심(e = 500 mm), 12등분

Ha = 1,600 mm, Xa = 1,000 mm

| 점 | φ | L₁ (mm) | L₂ (mm) | 경사길이 S (mm) | 누적각 ψ |
|---|---|---|---|---|---|
| 0 | 0° | 1,600.0 | 800.0 | 800.0 | 0° |
| 1 | 30° | 1,681.7 | 840.8 | 840.8 | 17.93° |
| 2 | 60° | 1,886.8 | 943.4 | 943.4 | 33.26° |
| 3 | 90° | 2,135.4 | 1,067.7 | 1,067.7 | 46.25° |
| 4 | 120° | 2,358.0 | 1,179.0 | 1,179.0 | 58.20° |
| 5 | 150° | 2,508.4 | 1,254.2 | 1,254.2 | 69.89° |
| 6 | 180° | 2,561.2 | 1,280.6 | 1,280.6 | 81.55° |
| 7 | 210° | 2,508.4 | 1,254.2 | 1,254.2 | 93.21° |
| 8 | 240° | 2,358.0 | 1,179.0 | 1,179.0 | 104.90° |
| 9 | 270° | 2,135.4 | 1,067.7 | 1,067.7 | 116.86° |
| 10 | 300° | 1,886.8 | 943.4 | 943.4 | 129.84° |
| 11 | 330° | 1,681.7 | 840.8 | 840.8 | 145.18° |
| 12 | 360° | 1,600.0 | 800.0 | 800.0 | 163.10° |

- 검산: 수직면(φ = 0°)의 경사 길이는 H(800 mm)와 같다.
- 반대쪽(φ = 180°)이 가장 긴 1,280.6 mm 다.
- 이음부(Seam)는 보통 가장 짧은 수직면 쪽에 둔다.

#### 3.2.6 필요 수치

3.1.4 의 동심 콘 수치에 더해 다음이 필요하다.

| 필요 수치 | 용도 |
|---|---|
| 편심량 (e) | 두 원 중심 간 거리, 가상 꼭짓점 위치 계산 |
| 편심 방향 | 수직면 위치 (하부 평탄 = FOB, 상부 평탄 = FOT) |
| 원주 분할 수 (n) | 전개 정밀도 (24~36등분 권장) |
| 이음부 위치 | 보통 가장 짧은 모선(수직면) 쪽 |

수직면 편심 콘이면 e = (D₁ − D₂)/2 로 자동 결정된다.

### 3.3 콘 실무

- 분할 수가 적으면 현(직선)으로 곡선을 근사하는 오차가 생긴다. 수작업은 24~36등분을 권장한다.
- 정밀 제작은 CAD 판금 전개(Sheet metal unfold) 기능으로 확인한다.
- 전체 각도가 크면 2분할 이상으로 나누어 철판 효율을 높인다.

## 4. 헤드 원판 (Blank)

곡률을 가진 헤드를 전개도로 그리고 철판 크기를 구하는 방법이다. 헤드는 성형 전 원판(Blank)의 지름으로 전개한다.

### 4.1 원리: 면적 동등법

성형 전 원판 면적 ≈ 성형 후 헤드 중립면(두께 중앙)의 표면적

Db = √(4A / π)

- A: 헤드 중립면 표면적 (평균지름 기준)
- 여기에 스트레이트 플랜지(SF)와 트림 여유를 더한다.

### 4.2 형식별 원판 지름 약산식

| 헤드 형식 | 원판 지름(Db) 약산식 | 비고 |
|---|---|---|
| 반구형 (Hemispherical) | Db ≈ 1.414 × Dm + 2·SF | 면적 2πR² → √2·D |
| 2:1 반타원형 (2:1 Ellipsoidal) | Db ≈ 1.2 × Dm + 2·SF | 계수 범위 1.18 ~ 1.2. 이론값 약 1.175 × D (4.3) |
| 접시형 (ASME F&D, 10% KR) | Db ≈ OD + OD/24 + 2·SF + (2/3)·IKR | 약 1.1 × OD 수준 |
| 평판형 플랜지 (Flat, Flanged) | Db ≈ D + 2·SF + (π/2 − 1)·r | r: 너클 반경 |

- 원문은 같은 표를 두 번 적었다. 앞의 표는 반구형·2:1·평판형의 지름을 D 로, 2:1 계수를 1.18 ~ 1.2 로 적었다. 뒤의 총정리 표는 반구형·2:1 의 지름을 Dm 으로, 2:1 계수를 1.2 로 적었고 평판형은 없다. 접시형 식은 두 표 모두 OD 를 쓴다.
- 트림 여유를 더한다. 제작사마다 다르며 보통 20~50 mm 다.
- 철판은 Db × Db 정사각형으로 산정한다 (정사각형 네스팅 기준).

### 4.3 2:1 타원형 이론 표면적 (참고)

- 장반경 a = D/2, 단반경 b = D/4
- 이심률 e = √(1 − b²/a²) ≈ 0.866 (여기의 e 는 편심량이 아니다)

A = πa² + (πb² / 2e) · ln[(1+e)/(1−e)] ≈ 1.38·πa²

→ Db = 2a·√1.38 ≈ 1.175·D

스트레이트 플랜지를 포함한 정밀식: Db = √(Db₀² + 4·D·SF). Db₀ 는 스트레이트 플랜지 없이 구한 원판 지름이다. 약산식의 "+2·SF" 는 이 값의 근사다.

### 4.4 분할·두께·구매

- 원판 지름이 철판 최대 폭(2,438 mm, 3,048 mm 등)을 넘으면 원판을 용접하거나, 크라운(중앙부) + 페탈(꽃잎형 조각)로 분할 전개한다.
- 성형 중 너클부 두께가 약 10% 줄어든다(Thinning). 두께 감소를 고려해 발주 두께를 정한다. 한 단계 두꺼운 판을 발주한다.
- 헤드는 대부분 전문 성형업체에서 구매하므로 최종 치수는 제작사 기준표로 확인한다. 실무에서는 업체에 형식·지름·두께·SF 를 주고 원판 치수는 업체 기준을 따르는 경우가 많다.

### 4.5 필요 수치

| 필요 수치 | 용도 |
|---|---|
| 헤드 형식 | 반구형, 2:1 타원형, 접시형(F&D) 등 계산식 선택 |
| 지름 (ID 또는 OD) | 원판 지름 계산 |
| 두께 (t) 및 최소 성형 후 두께 | 두께 감소 고려한 발주 두께 |
| 스트레이트 플랜지 (SF) | 원판 지름에 2·SF 추가 |
| 크라운 반경 (CR) | 접시형 헤드 |
| 너클 반경 (KR/IKR) | 접시형 헤드 |
| 헤드 깊이 (내측 깊이) | 형상 검증 |
| 분할 여부 | 원판이 철판 폭보다 크면 크라운 + 페탈 분할 |

- 2:1 타원형·반구형은 지름과 SF 만으로 계산할 수 있다.
- 접시형은 크라운 반경과 너클 반경이 반드시 있어야 한다.

### 4.6 예제 (2:1 타원형)

OD 1,000 mm, t = 10 mm, SF = 50 mm, 트림 여유 30 mm

1. 평균지름 Dm = 1,000 − 10 = 990 mm
2. Db = 1.2 × 990 + 2 × 50 = 1,288 mm
3. 트림 여유 포함: 1,288 + 30 ≈ 1,318 mm
4. 필요 철판: 약 1,320 × 1,320 mm (정사각형 네스팅 기준)

## 5. 철판 중량

- 탄소강: 중량(kg) = 가로(m) × 세로(m) × 두께(mm) × 7.85
- 스테인리스강: 비중 약 7.93 을 적용한다.

## 6. 재료 시험 지표: 연신율과 단면수축률

질의 원문은 "연식율 공식"이었다. 원문은 이를 재료 인장시험의 연신율(延伸率, Elongation)로 해석해 답했다. 그 해석이 맞는지는 확인되지 않았다. 이 문서의 전개 식에는 쓰이지 않는다.

연신율(%) = (L − L₀) / L₀ × 100

- L₀: 시험 전 원래 표점거리(Gauge length)
- L: 파단 후 시험편을 맞대어 측정한 표점거리

재료가 끊어지기 전까지 원래 길이 대비 얼마나 늘어났는지를 백분율로 나타낸다. 값이 클수록 연성이 좋은 재료다.

예: 원래 표점거리 50 mm, 파단 후 60 mm 이면 (60 − 50) / 50 × 100 = 20%

함께 쓰이는 지표인 단면수축률은 다음과 같다.

단면수축률(%) = (A₀ − A) / A₀ × 100

- A₀: 원래 단면적
- A: 파단부의 최소 단면적

## 7. 검토 메모 (원문에 없는 내용, 2026-10-23)

### 7.1 받은 커팅플랜과 대조

설비 2개(D-1203, S-2120)의 커팅플랜과 설계 도면 치수로 대조했다.

- 쉘: 커팅플랜의 쉘 전개 길이가 π × Dm 과 1 mm 안에서 맞는다. 프리벤딩·트림 여유는 더해져 있지 않다.
- 2:1 헤드: 원판 3개가 1.2 × Dm + 2·SF + 트림 30 과 20 mm 안에서 맞는다. 거꾸로 구한 트림 여유는 14, 24, 46 mm 다.
- 헤드 두께: S-2120 도면은 헤드마다 MIN. TH'K (AFTER FORMING) 과 USED TH'K 를 함께 적었다 (TOP 8.5 와 10, BTM 6.8 과 8). 커팅플랜의 판 두께는 USED TH'K 다. 원판 식의 t 도 USED TH'K 로 넣었다.
- 콘: D-1203 의 콘 2개는 안지름 기준 전개와 0.1 mm 까지 맞는다. 평균지름 기준보다 폭이 31 mm 작다. 담당자 확인 전까지는 1.1 의 원칙대로 평균지름을 쓴다.

### 7.2 원문 식에서 확인할 곳

담당자 확인 전까지는 원문 식을 그대로 쓴다.

- 평판형 플랜지: 너클 항 (π/2 − 1)·r 는 한쪽 몫으로 보인다. 단면 길이로 원판 지름을 구하면 (D − 2r) + πr + 2·SF = D + 2·SF + (π − 2)·r 이다. 2·SF 는 양쪽 몫이므로 너클 항만 절반이다.
- 접시형(F&D): 식에 크라운 반경(CR)이 없다. 4.5 는 CR 이 반드시 있어야 한다고 한다. CR = OD 인 표준 형상을 전제한 식으로 보인다. "약 1.1 × OD" 는 IKR ≈ 0.1 × OD 일 때 맞는다 (1.108 × OD).
- 2:1 반타원형: 약산식의 +2·SF 는 4.3 정밀식보다 크다. 4.6 예제 조건(Dm 990, SF 50, 트림 전)에서 정밀식은 Db₀ = 1.175 × Dm 이면 1,245.5 mm, Db₀ = 1.2 × Dm 이면 1,268.6 mm 이고, 약산식은 1,288 mm 다.
