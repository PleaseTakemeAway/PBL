# 압력용기 쉘·콘·헤드 전개도 및 철판 크기 계산 정리

> 대화 내용을 순서대로 정리한 문서입니다.
> 모든 전개 계산은 **평균지름(Dm)** 기준이 원칙입니다.
> - 내경 기준 도면: Dm = ID + t
> - 외경 기준 도면: Dm = OD − t

## 1. 연신율 공식

**Q. 연식율 공식을 알고 있어?**

재료 인장시험에서 쓰는 **연신율(延伸率, Elongation)**으로 해석하여 정리했습니다.

**연신율(%) = (L − L₀) / L₀ × 100**

- L₀: 시험 전 원래 표점거리(Gauge length)
- L: 파단 후 시험편을 맞대어 측정한 표점거리

재료가 끊어지기 전까지 원래 길이 대비 얼마나 늘어났는지를 백분율로 나타내며, 값이 클수록 연성이 좋은 재료입니다.

**예시:** 원래 표점거리 50 mm → 파단 후 60 mm
(60 − 50) / 50 × 100 = **20%**

**함께 쓰이는 지표 – 단면수축률**

단면수축률(%) = (A₀ − A) / A₀ × 100

- A₀: 원래 단면적
- A: 파단부의 최소 단면적

## 2. 헤드 원판(Blank) 크기 계산

**Q. 도면에서 곡률을 가진 shell의 head를 전개도로 그리고 철판 사이즈를 계산하는 계산식을 알려줘.**

### 2.1 기본 원리 – 면적 동등법

성형 전 원판 면적 ≈ 성형 후 헤드 중립면(두께 중앙)의 표면적

**Db = √(4A / π)**

- A: 헤드 중립면 표면적 (평균지름 기준)
- 여기에 스트레이트 플랜지(SF)와 트림 여유를 더함

### 2.2 헤드 형식별 원판 지름 약산식

| 헤드 형식 | 원판 지름(Db) 약산식 | 비고 |
|---|---|---|
| 반구형 (Hemispherical) | Db ≈ 1.414 × D + 2·SF | 면적 2πR² → √2·D |
| 2:1 반타원형 (2:1 Ellipsoidal) | Db ≈ 1.18 ~ 1.2 × D + 2·SF | 이론값 약 1.175 × D |
| 접시형 (ASME F&D, 10% KR) | Db ≈ OD + OD/24 + 2·SF + (2/3)·IKR | 약 1.1 × OD 수준 |
| 평판형 플랜지 (Flat, Flanged) | Db ≈ D + 2·SF + (π/2 − 1)·r | r: 너클 반경 |

- SF: 스트레이트 플랜지 길이
- IKR: 내측 너클 반경 (Inside Knuckle Radius)

### 2.3 2:1 타원형 이론 표면적 (참고)

- 장반경 a = D/2, 단반경 b = D/4
- 이심률 e = √(1 − b²/a²) ≈ 0.866

A = πa² + (πb² / 2e) · ln[(1+e)/(1−e)] ≈ 1.38·πa²

→ Db = 2a·√1.38 ≈ **1.175·D**

**스트레이트 플랜지 포함 정밀식:** Db = √(Db₀² + 4·D·SF)
(약산식의 "+2·SF"는 이 값의 근사)

### 2.4 계산 예시 (2:1 타원형)

조건: OD 1,000 mm, t = 10 mm, SF = 50 mm, 트림 여유 30 mm

1. 평균지름 Dm = 1,000 − 10 = 990 mm
2. Db = 1.2 × 990 + 2 × 50 = 1,288 mm
3. 트림 여유 포함: 1,288 + 30 ≈ **1,318 mm**
4. 필요 철판: 약 **1,320 × 1,320 mm** (정사각형 네스팅 기준)

### 2.5 실무 주의사항

- 원판 지름이 철판 최대 폭(2,438 mm, 3,048 mm 등)을 넘으면 원판을 용접하거나, 크라운(중앙부) + 페탈(꽃잎형 조각)로 분할 전개
- 성형 중 너클부 두께 감소(Thinning) 약 10% → 한 단계 두꺼운 판 발주
- 트림 여유는 제작사마다 다르며 보통 20~50 mm
- 헤드는 대부분 전문 성형업체에서 구매하므로 최종 치수는 제작사 기준표로 확인

## 3. 쉘·콘·헤드 철판 크기 계산식 총정리

**Q. 콘, 쉘, 헤드 부분의 철판 크기를 계산할 때 지정 계산식이 있으면 정리해줄래?**

### 3.1 원통 쉘 (Cylindrical Shell)

- 전개 길이(원주 방향): **L = π × Dm**
- 전개 폭(축 방향): **W = 쉘 길이(H)**
- 철판 크기: **(π × Dm) × H**

**예시:** ID 1,500 mm, t = 12 mm, 길이 3,000 mm

- Dm = 1,512 mm
- L = π × 1,512 ≈ 4,750 mm
- 철판 크기: **4,750 × 3,000 mm**
- 한 장으로 나오지 않으면 여러 코스(Course)로 나누고, 길이 방향 이음(Long seam)은 코스끼리 엇갈리게 배치

**실무 여유:** 롤링 전 양 끝단의 프리벤딩(Pre-bending) 여유나 트림 여유를 제작사 기준에 따라 추가

### 3.2 원추 (Concentric Cone)

→ 4장 참고

### 3.3 헤드 (Head)

| 헤드 형식 | 원판 지름(Db) 약산식 |
|---|---|
| 반구형 | 1.414 × Dm + 2·SF |
| 2:1 반타원형 | 1.2 × Dm + 2·SF |
| 접시형 (ASME F&D) | OD + OD/24 + 2·SF + (2/3)·IKR |

- 트림 여유(20~50 mm) 추가
- 철판은 Db × Db 정사각형으로 산정
- 두께 감소(약 10%) 고려하여 발주 두께 결정

## 4. 콘 전개 계산식 (동심 / 편심)

**Q. 콘의 경우도 계산식이 있어? 동심, 편심 모두.**

### 4.1 동심 콘 (Concentric Cone)

기호: D₁ = 대경, D₂ = 소경 (둘 다 평균지름), H = 콘 높이

| 항목 | 계산식 |
|---|---|
| ① 반정각 | tan α = (D₁ − D₂) / (2H) |
| ② 경사 길이 | S = √[ H² + ((D₁ − D₂)/2)² ] |
| ③ 외측 전개 반경 | R₁ = D₁ / (2 sin α) |
| ③ 내측 전개 반경 | R₂ = D₂ / (2 sin α) |
| 검산 | R₁ − R₂ = S |
| ④ 전개 각도 | θ = 360° × sin α |

**⑤ 필요 철판 크기 (부채꼴 1장 기준)**

| 조건 | 철판 폭 | 철판 높이 |
|---|---|---|
| θ ≤ 180° | 2R₁ · sin(θ/2) | R₁ − R₂ · cos(θ/2) |
| θ > 180° | 2R₁ | R₁ · (1 − cos(θ/2)) |

- θ가 크면 2~4분할로 나눔 → n분할 시 각 조각 각도 θ/n을 위 표에 대입
- 도면에 반정각만 있으면: H = (D₁ − D₂) / (2·tan α)

**예시:** D₁ = 2,000 mm, D₂ = 1,000 mm, H = 800 mm

1. tan α = 500 / 800 = 0.625 → α ≈ 32.0°, sin α ≈ 0.530
2. R₁ = 2,000 / (2 × 0.530) ≈ 1,887 mm
3. R₂ ≈ 943 mm
4. θ = 360 × 0.530 ≈ 190.8° (180° 초과)
5. 1장: 약 3,774 × 2,065 mm (너무 큼)
6. 2분할: 각 조각 95.4° → 조각당 약 **2,791 × 1,252 mm × 2장**

### 4.2 편심 콘 (Eccentric Cone)

편심 콘은 연장하면 꼭짓점이 한쪽으로 기울어진 **사원추(Oblique cone)**가 됩니다. 모선 길이가 위치마다 달라 부채꼴이 되지 않으므로, 둘레를 n등분해 각 점을 계산하는 **방사선법/삼각분할법**을 사용합니다.

기호: D₁, D₂, H + **e (두 원 중심 간 편심량)**
- 한쪽 면이 수직인 일반 편심 콘: e = (D₁ − D₂)/2

**① 가상 꼭짓점 위치**

- 꼭짓점 높이(대경 기준): **Ha = H × D₁ / (D₁ − D₂)**
- 꼭짓점 수평 위치(대경 중심에서): **Xa = e × D₁ / (D₁ − D₂)**

**② 각 점의 모선 길이**

대경 원주를 n등분, φ = 360° × i / n (φ = 0°는 편심 방향), r₁ = D₁/2

**L₁(φ) = √[ (r₁·cos φ − Xa)² + (r₁·sin φ)² + Ha² ]**

수직면 편심 콘(Xa = r₁)이면:

**L₁(φ) = √[ 4r₁²·sin²(φ/2) + Ha² ]**

- 소경 쪽 모선 길이: **L₂(φ) = L₁(φ) × D₂ / D₁**
- 실제 콘 경사 길이: **S(φ) = L₁(φ) − L₂(φ)**

**③ 전개 각도 (삼각형 이어붙이기)**

- 대경 원주 분할 현 길이: **c = D₁ · sin(180°/n)**
- 이웃 모선 사이 전개 각:

**δᵢ = arccos[ (Lᵢ² + Lᵢ₊₁² − c²) / (2·Lᵢ·Lᵢ₊₁) ]**

- 누적 각도: **ψᵢ = δ₁ + δ₂ + … + δᵢ**

**④ 전개도 좌표 (꼭짓점 = 원점)**

- 대경 쪽 점: (L₁·cos ψ, L₁·sin ψ)
- 소경 쪽 점: (L₂·cos ψ, L₂·sin ψ)

점들을 매끄럽게 이으면 전개도가 되며, 좌표의 최대·최소값으로 철판 크기(외접 사각형)를 구합니다.

**예시:** D₁ = 2,000 mm, D₂ = 1,000 mm, H = 800 mm, 수직면 편심(e = 500 mm), 12등분

Ha = 1,600 mm, Xa = 1,000 mm

| 점 | φ | L₁ (mm) | L₂ (mm) | 경사길이 S (mm) | 누적각 ψ |
|---|---|---|---|---|---|
| 0 | 0° | 1,600.0 | 800.0 | 800.0 | 0° |
| 1 | 30° | 1,681.7 | 840.8 | 840.8 | 17.93° |
| 2 | 60° | 1,886.8 | 943.4 | 943.4 | 33.26° |
| 3 | 90° | 2,135.4 | 1,067.7 | 1,067.7 | 46.25° |
| 4 | 120° | 2,358.0 | 1,179.0 | 1,179.0 | 58.20° |
| 5 | 150° | 2,508.4 | 1,254.2 | 1,254.2 | 69.89° |
| 6 | 180° | 2,561.2 | 1,280.6 | 1,280.6 | 81.55° |
| 7 | 210° | 2,508.4 | 1,254.2 | 1,254.2 | 93.21° |
| 8 | 240° | 2,358.0 | 1,179.0 | 1,179.0 | 104.90° |
| 9 | 270° | 2,135.4 | 1,067.7 | 1,067.7 | 116.86° |
| 10 | 300° | 1,886.8 | 943.4 | 943.4 | 129.84° |
| 11 | 330° | 1,681.7 | 840.8 | 840.8 | 145.18° |
| 12 | 360° | 1,600.0 | 800.0 | 800.0 | 163.10° |

- 검산: 수직면(φ = 0°) 경사 길이 = H(800 mm)
- 반대쪽(φ = 180°)이 가장 긴 1,280.6 mm
- 이음부(Seam)는 보통 가장 짧은 수직면 쪽에 배치

### 4.3 실무 팁

- 분할 수가 적으면 현(직선)으로 곡선을 근사하는 오차 발생 → 수작업은 24~36등분 권장
- 정밀 제작은 CAD 판금 전개(Sheet metal unfold) 기능으로 확인
- 전체 각도가 크면 2분할 이상으로 나누어 철판 효율 향상

## 5. 전개도 작성에 필요한 수치

**Q. 각 콘, 쉘, 헤드의 전개도를 그리려면 필요한 수치들은 뭐야?**

### 5.1 공통 필요 수치

- **두께(t)** 및 **치수 기준(ID 또는 OD)** → 평균지름(Dm) 계산
- **재질** → 중량 계산, 성형 특성
- **트림·가공 여유** → 개선 가공, 절단 여유
- **사용 가능한 철판 규격** (예: 2,438 × 6,096 mm) → 분할 여부 결정

### 5.2 쉘 (Cylindrical Shell)

| 필요 수치 | 용도 |
|---|---|
| 지름 (ID 또는 OD) | 평균지름 → 원주 길이 π·Dm |
| 쉘 길이 (H) | 전개 폭 |
| 두께 (t) | 평균지름 계산 |
| 코스 분할 위치 | 원주 이음(Circ. seam) 위치 결정 |
| 길이 이음 위치/방향 | 코스끼리 엇갈림 배치 |
| 노즐·맨홀 위치와 크기 | 개구부가 용접선을 피하도록 배치 |
| 롤링·프리벤딩 여유 | 실제 절단 치수 |

### 5.3 동심 콘 (Concentric Cone)

| 필요 수치 | 용도 |
|---|---|
| 대경 (D₁) | 외측 전개 반경 R₁ |
| 소경 (D₂) | 내측 전개 반경 R₂ |
| 콘 높이 (H) 또는 반정각 (α) | 둘 중 하나만 있으면 나머지 계산 가능 |
| 두께 (t) | 평균지름 계산 |
| 너클·토로이달 유무와 반경 | 있으면 별도 부품으로 전개 |
| 분할 수 | 전개 각도가 크면 2~4분할 |

### 5.4 편심 콘 (Eccentric Cone)

동심 콘 수치에 추가로:

| 필요 수치 | 용도 |
|---|---|
| 편심량 (e) | 두 원 중심 간 거리, 가상 꼭짓점 위치 계산 |
| 편심 방향 | 수직면 위치 (하부 평탄 = FOB, 상부 평탄 = FOT) |
| 원주 분할 수 (n) | 전개 정밀도 (24~36등분 권장) |
| 이음부 위치 | 보통 가장 짧은 모선(수직면) 쪽 |

※ 수직면 편심 콘이면 e = (D₁ − D₂)/2 로 자동 결정

### 5.5 헤드 (Head)

| 필요 수치 | 용도 |
|---|---|
| 헤드 형식 | 반구형, 2:1 타원형, 접시형(F&D) 등 계산식 선택 |
| 지름 (ID 또는 OD) | 원판 지름 계산 |
| 두께 (t) 및 최소 성형 후 두께 | 두께 감소 고려한 발주 두께 |
| 스트레이트 플랜지 (SF) | 원판 지름에 2·SF 추가 |
| 크라운 반경 (CR) | 접시형 헤드 |
| 너클 반경 (KR/IKR) | 접시형 헤드 |
| 헤드 깊이 (내측 깊이) | 형상 검증 |
| 분할 여부 | 원판이 철판 폭보다 크면 크라운 + 페탈 분할 |

- 2:1 타원형·반구형: 지름과 SF만으로 계산 가능
- 접시형: **크라운 반경과 너클 반경 필수**
- 실무에서는 업체에 형식·지름·두께·SF를 주고 원판 치수는 업체 기준을 따르는 경우가 많음

### 5.6 작업 흐름 요약

1. 형상 치수(지름, 높이, 반경, 편심량)로 전개 형상 계산
2. 두께로 평균지름 보정
3. 이음 위치·여유·철판 규격으로 실제 절단 치수와 분할 결정

## 6. 공통: 철판 중량 계산

**탄소강:**

중량(kg) = 가로(m) × 세로(m) × 두께(mm) × **7.85**

**스테인리스강:** 비중 약 **7.93** 적용
