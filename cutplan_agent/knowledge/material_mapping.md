# 재질 표기 정규화

| 도면/BOM 표기 | 정규화 키 | 비고 |
|---|---|---|
| SA516-70, A516-70, SA 516 GR.70, SA516-70N | SA516-70 (+N 은 노멀라이징 플래그) | ASME SA = ASTM A. 커팅플랜에서는 같은 그룹으로 묶어도 되지만 **N 여부는 유지** (발주 규격이 다름) |
| SA516-60, A516-60 | SA516-60 | |
| SA283-C, A283-C, SA283 GR.C | SA283-C | 일반 구조용. 러그·베이스·리브 |
| SA285-C, A285-C | SA285-C | |
| SA240-304, A240-304, SUS304, 304 S.S | SA240-304 | 스테인리스. 탄소강과 절대 같은 판에 배치 금지 |
| SA240-304L / 316L | SA240-304L / SA240-316L | |
| SS400 (KS) ↔ St37 (DIN) ↔ A283-C/A36 급 | SS400 | HCE 판금 BOM 은 SS400, TruTops 는 St37-40 로 적힘 |
| SPCC, SPHC | 성형용 냉연/열연 | 프레스 성형품. 전개 대상 아님 |
| S20C, SA105, SA182-F304 | 단조·봉·너트 | 판재 아님 → 커팅플랜 제외 |
| B168-N06600 (Inconel 600) | 니켈합금 판 | 별도 판, 별도 POR 행 |
| 클래드 `t16(13+3)` | 모재 13 + 클래드 3 | 두께 키는 16, clad 플래그 |

규칙
- 판재 여부 판정: MATERIAL 이 판 규격(SA516/SA283/SA285/SA240/SS400/B168 …) 이고 SIZE 가 `t` 두께를 가지면 판재. 파이프 규격(SA106, SCH40), 단조(SA105, SA182), 볼트·너트는 제외.
- 그룹 키 = (정규화 재질, 두께, clad). 네스팅·POR 행은 이 키 단위.
- 두께 표기 `t10`, `10t`, `10T`, `THK 10`, `SS400,6t` 모두 10 / 6 으로.
