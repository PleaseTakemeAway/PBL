# 네스팅(커팅플랜 배치) 규칙 — KDM 배치툴 프로토타입 기준

- 그룹: (재질, 두께) 가 같은 조각만 한 판에. 클래드·스테인리스는 탄소강과 분리.
- 회전: 0 / 90 / 180 / 270 허용. 압연 방향 지정이 있는 부품(쉘 롱심 방향)은 도면 지시 우선.
- 간격: 커팅여유(가스 20) 보다 가까우면 충돌. 판 가장자리 10.
- 큰 조각 먼저(면적 내림차순), 쉘·헤드·콘이 판 크기를 결정하고 패드·러그는 자투리에.
- 판 크기: 표준폭 중 선택, 길이는 100 단위 맞춤(운반 상한 12000×3050). 판마다 다른 규격 허용(멀티규격).
- 목표 지표: 판 수 최소 → 총 gross 중량 최소 → 활용률 최대. 활용률 = Σ조각 실제면적 / 판 면적.
- 결과물: 판별 배치 좌표 + 라벨 `재질 t두께 x 폭 x 길이 - n SH'T` (기존 CP 도면 형식과 동일).
- 검증: 겹침 0, 여유 위반 0, 모든 조각 배치 완료(배치 n/n), 판 수·중량이 사람 커팅플랜과 비교.
- 향후: NFP 엔진(SVGnest/Deepnest) 로 곡선 맞물림. 현재는 bbox 기반 shelf 배치.
